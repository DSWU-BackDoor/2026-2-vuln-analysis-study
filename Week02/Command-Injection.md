# Command Injection

## 1. Command Injection의 개념과 위험성

Command Injection은 애플리케이션이 사용자 입력을 운영체제 명령어 실행에 사용하면서 공격자가 의도하지 않은 OS 명령을 실행할 수 있게 되는 취약점이다.

SQL Injection이 SQL 명령어를 대상으로 한다면,

```text
SQL Injection
→ SQL 명령 조작

Command Injection
→ OS 명령 조작
```

으로 구분할 수 있다.

### 위험성

Command Injection이 발생하면 애플리케이션이 실행되는 서버에서 공격자가 의도하지 않은 명령이 실행될 수 있기 때문에 서버의 파일, 프로세스 및 시스템 자원 등에 영향을 줄 수 있다.

## 2. `system()` 함수 사용 시 발생할 수 있는 보안 문제

`system()`과 같이 문자열을 운영체제 명령으로 전달하여 실행하는 함수는 사용자 입력값이 명령어에 포함되는 경우 보안 문제가 발생할 수 있다.

예를 들어 다음과 같이 사용자 입력을 그대로 명령어에 포함시키는 구조는 위험하다.

> > 사용자 입력

    ↓

명령어 문자열에 삽입
↓
system()
↓
OS 명령 실행

특히 사용자 입력에 명령어의 실행 구조를 변경할 수 있는 문자가 포함될 경우, 원래 개발자가 의도한 명령과 다른 명령이 실행될 가능성이 있다.

따라서 `system()`을 사용할 때는 사용자 입력을 직접 명령어 문자열에 결합하지 않는 것이 중요하다.
